# Milestone 9.5: Invisible Interface

## Executive Definition

**M9.5 is successful when:**
- A first-time user understands Synth by using it
- Approvals feel conversational, not administrative
- Memory feels recalled, not queried
- Cognitive Field feels like "thinking", even though it's read-only
- You can demo Synth live without explaining the UI

At that point, Synth is no longer "a system". It's an interface to a digital mind.

## Success Criteria

### 1. Invisible Onboarding
- First-time user can start using Synth without reading docs
- Natural language flows, UI elements reveal themselves as needed
- No "getting started" tour needed

### 2. Conversational Approvals
- Approval requests read like a dialogue, not a bureaucracy
- Contextual, brief, human-paced
- Approver feels like a collaborator, not a gatekeeper

### 3. Ambient Memory
- Recent context available without explicit queries
- "I remember we talked about X" moments
- Memory feels innate, not retrieved

### 4. Cognitive Field = Thinking
- Read-only panel reads like internal monologue
- Visually conveys mental activity
- User understands Synth is "working" even when silent

### 5. Demo-Ready Without Tour
- Can show Synth to a stranger and have them "get it" in <2 minutes
- No explanation of architecture, only interaction

## In Scope

- Approval flow redesign for conversational tone
- Memory auto-load and ambient context injection
- Cognitive Field visual refresh (thinking visualization)
- TUI polish: reduced cognitive load, intuitive hierarchy
- Help/tooltips that contextually appear only when needed

## Out of Scope

- New execution capabilities
- Autonomy features (M10)
- External integrations
- New tools
- Scheduler

## Next: M10 (After M9.5)

Once M9.5 stabilizes:
- **M10: Runtime Shadow Overlay** — passive cognitive field ticks
- Still no autonomy, but visible internal activity
- First moment Synth appears alive between runs

Autonomy is initiative, not execution:
- Runtime can decide to think and propose actions
- Cannot act without approval
- NeuronWaves remains the execution engine
- Policy and approvals remain mandatory
